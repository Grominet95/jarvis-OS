# Logs and Doctor

## Log locations (Windows run)

`%TEMP%\jarvis\livekit.log`, `api.log`, `voice.log`

## Doctor

`.\jarvis.ps1 doctor` — environment diagnostics.

## Preflight

`python -m jarvis.kernel.preflight` — runs before API start on `run`.
